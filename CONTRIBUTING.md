# Contributing to Boxophone

Contributions improving accessibility, browser compatibility, audio quality, performance, and MIDI reliability are welcome.

This project uses plain HTML, CSS, and JavaScript without a compile step. Serve it over localhost to test MIDI and consent. New assets must be original or explicitly licensed for redistribution. Do not add CDN dependencies, telemetry of note content, or secret keys. Test keyboard accessibility, touch behavior, and note-off edge cases whenever changing input handling.

The Buildiful® brand name and official marks are not included in the code license. See `TRADEMARKS.md`.
